# wispr-fox v2.1.0-nightly.6

The onboarding grew up.

## Pick your engine

Setup no longer assumes Groq. The second screen now offers two engines,
each with an honest pitch:

- **Deepgram** *(recommended)* — Nova-3 is faster and noticeably more
  accurate than Whisper, especially with Indian accents. You get **$200
  free credit on signup with no card**, and heavy daily use burns about
  $1 a week — so it lasts a year or more.
- **Groq** *(free forever)* — ~2,000 free transcriptions a day, resets
  daily, and one key also powers the cleanup/Draft brain.

The smart deep-links do the legwork: the first click opens the signup
page, the second lands you on the API-keys page. Keys are verified live
as you paste them, and picking Deepgram automatically points the app at
Nova-3. On the Deepgram path there's an optional third step to add the
free Groq "brain" so cleanup and Draft mode work too.

## It also looks the part

Soft colour fields drift behind the pages, headlines get a warm gradient,
cards rise in one after another, screens slide in, and a little
typewriter line shows what dictation feels like before you've set
anything up. (All of it respects reduced-motion settings.)

## Docs to match

The README and the product site now tell the same story: providers in
general, Deepgram recommended with the $200-credit math, Groq free
forever.
